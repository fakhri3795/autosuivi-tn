# AutoSuivi TN - Project Instructions

## Overview
Vehicle tracking & predictive maintenance app for Tunisia. Dark theme (#0D1117 bg, #1C2128 surface) with orange accent (#F97316 primary, #F59E0B accent).

## Architecture
- **Frontend**: React Native / Expo at `/home/ubuntu/autosuivi-tn/`
- **Backend**: Remote VPS at `http://102.204.205.49/api` (DO NOT modify)
- Clean Architecture: domain/entities, data/repositories, data/services, presentation/components, presentation/context

## Key Decisions (v2.1.0)
- **Date formats**: All dates use `month: 'long'` for full month names across all screens
- **ThemedDatePicker**: Custom component using `react-native-paper-dates` with dark theme + orange accent, replaces system DateTimePicker on all platforms
- **NotificationService**: Local notifications using expo-notifications. Scheduled 7 days before deadlines, 500km before maintenance targets
- **KM Card**: Dashboard km card is clickable (opens km update modal) with pen icon hint
- **PredictionItem**: Has `lastMaintenanceKm` field for tracking last maintenance km

## Navigation
- expo-router file-based routing
- Tabs: Dashboard, Maintenance, Deadlines, Mileage, Vehicles
- Modals: Vehicle form, Maintenance form

## State Management
- VehicleContext provides all data + CRUD operations
- Auth via AuthContext with JWT tokens
- Maintenance intervals stored locally (AsyncStorage)
